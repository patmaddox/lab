Install the shared jail defaults once, before building or running any
jail. Each instance jail.conf includes it by absolute path:
#+BEGIN_EXAMPLE
cp share/jail.defaults.conf /etc/jail.conf.d/defaults.conf
#+END_EXAMPLE

* operate
The Justfile drives a jail through service(8), which finds its config by
name in =/etc/jail.conf.d=:
#+BEGIN_EXAMPLE
just install   # copy jail.conf to /etc/jail.conf.d/<name>.conf
just start     # service jail onestart <name>
just status    # running or stopped
just stop      # service jail onestop <name>
#+END_EXAMPLE

jails get either =origin.git= as =rw=, or =ro= with =submissions.git=
as =rw= depending on permissions. i.e. developer gets =rw= access to
=origin.git= whereas agent jails get =ro= access to =origin.git= and
=rw= access to =submissions.git=.
