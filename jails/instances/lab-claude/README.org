#+TITLE: lab-claude

* mail
lab-claude reads and posts to the list on lab-mail, which holds the
Fastmail credentials. Both services listen on loopback, so the setup
below needs no secrets. See =../lab-mail/spec.org=.

lab-process-mail reads and answers the list this way.

** set up
lab-claude needs no password and no config by hand. Its configs are
in =dist/home/claude= and the jail installs them:
- =.mbsyncrc= pulls the list from lab-mail as =claude@p7x.dev=;
- =.msmtprc= posts through lab-mail;
- =.config/notmuch/lab-mail/config= is the notmuch profile;
- =.gitconfig= has git send-email post through msmtp.

A jail built before them takes each file from =dist/home/claude= into
=~claude= by hand, with the mode =dist.mtree= gives it.

Then, as claude, run =~/bootstrap.sh=. It installs the notmuch
package from =dotfiles/notmuch=, which brings the profile's hooks, and
makes the mail root with the list's folders. Sync, index, and check:
#+BEGIN_EXAMPLE
~/bootstrap.sh
mbsync lab-mail && NOTMUCH_PROFILE=lab-mail notmuch new
cd ~/lab/default.jj/dotfiles/notmuch && just check
#+END_EXAMPLE

Last, install lab-process-mail from =src/lab-process-mail=, so each
pass syncs and answers the list on lab-mail:
#+BEGIN_EXAMPLE
cd ~/lab/default.jj/src/lab-process-mail && just install
#+END_EXAMPLE

To start over, remove =~/mail/claude@p7x.dev= and run =~/bootstrap.sh=
again. mbsync keeps its state in each folder, so the next sync pulls
the whole list.

** fetch and read
mbsync pulls the list's folders, INBOX, =Next=, =Later=, and
=Archive=, into =~/mail/claude@p7x.dev=, and notmuch indexes them
under the profile =lab-mail=, whose hooks come from
=dotfiles/notmuch=:
#+BEGIN_EXAMPLE
mbsync lab-mail && NOTMUCH_PROFILE=lab-mail notmuch new
NOTMUCH_PROFILE=lab-mail notmuch search tag:inbox
NOTMUCH_PROFILE=lab-mail notmuch show id:<message-id>
#+END_EXAMPLE

The sync only pulls. claude@p7x.dev cannot change the list, and a
message Pat moves or deletes on lab-mail moves or goes here too.

=just check= in =~/lab/default.jj/dotfiles/notmuch= checks this
setup and changes nothing.

lab-mail syncs with Fastmail once a minute, so a message sent to the
list through Fastmail shows up here within two minutes.

** post
msmtp posts as claude@p7x.dev. With =-t= it takes the recipients
from the To, Cc and Bcc headers:
#+BEGIN_EXAMPLE
msmtp -t < message.eml
#+END_EXAMPLE

git send-email posts a patch series through msmtp, as =.gitconfig=
sets, taking the recipients from each patch:
#+BEGIN_EXAMPLE
git send-email /tmp/series/*.patch
#+END_EXAMPLE

lab-mail delivers mail for =lab-devel@p7x.dev=, =lab@lists.p7x.dev=,
and =freebsd-ports@lists.p7x.dev= to the list, and
accepts and discards mail for =pat@p7x.dev=, =pat@patmaddox.com=, and
=claude@p7x.dev=, who read the list. It refuses any other recipient,
and a message whose header it cannot parse. msmtp then exits non-zero
with lab-mail's reply, and the message goes to no one; fix it and
post again. Nothing leaves lab-mail, so mail for anyone outside the
list cannot be sent from here.
