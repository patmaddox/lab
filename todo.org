* TODO Document command progression maturity levels
Commands evolve through stages as they prove useful:
1. Description in a Claude skill (SKILL.md) — Claude interprets instructions
2. Script embedded in Claude skill — reusable but coupled to skill
3. Standalone script — usable outside Claude
4. Just command — discoverable via =just -l=, composable
5. First-class command — standalone binary/script on PATH, no just dependency
6. Emacs command — streamlines multi-step terminal workflows with
   state and inspection. Example: =jj submittable= → =jj show foo=
   → =jj submit foo= becomes a single emacs command that shows the
   top of the submittable stack, lets you inspect, and submits.
Each stage adds independence from the scaffolding that preceded it.
