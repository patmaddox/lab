# emacs config

This directory holds my emacs configuration.

Goals:

- clean, fast setup
- minimize cognitive load
- powerful but simple
- easy to extend and integrate with other tools

Functionality:

- programming (Elixir, freebsd-src, freebsd-ports, Rust, Go, shell
  scripts, other languages)
- terminal emulator - including SSH to other servers
- remote editing and access
- work on multiple projects at once

Context:

Emacs (X, not terminal) on FreeBSD

Dependencies are provided by FreeBSD ports tree rather than an emacs
package manager.
