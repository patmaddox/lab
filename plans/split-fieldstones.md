# Split fieldstones.org into separate files

fieldstones.org is a single file that grows over time. As it gets
larger, it becomes harder for LLMs to consume and for humans to
navigate. Split each fieldstone into its own file in a fieldstones/
directory, similar to how plans are individual files.

Need to figure out: indexing (generated index like plans?), how
Emacs capture workflows adapt, whether org format still makes sense
