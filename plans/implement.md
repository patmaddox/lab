# Create a prompt for implementing plans

prompts/plan.md handles developing plans -- iterating on them until
they're ready. There is no prompt for the other half: picking up a
ready plan and implementing it. The implementation instructions
currently live in the Plans section of CLAUDE.md and need a proper
home.

Implementation covers: reading the plan, implementing tasks, checking
dependencies, writing a postmortem, updating status, and archiving.
