Welcome to my site.

The primary purpose of this site is to document my experience building software.
I keep a monorepo with all of the projects I work on, including open source projects.
This gets unwieldy at times, and I forget how to use it.
I need to write documentation to help me operate it.

I used a Fossil site in the past, and I really liked it.
I liked the integration of source code and content.
However, I've started to use jujutsu as an interface to git, and it's so good that I've abandoned Fossil.

Now I'm starting over with this new website.
