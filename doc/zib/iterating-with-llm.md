---
title: iterating with LLM
---

LLM is a programmable system, like Unix. Similar principles apply. Set
a goal, develop a process, refine it.

It makes sense to do things somewhat manually, in an exploratory manner.

For example, I am developing a research process. It started by writing
single markdown files, then has evolved to an org file. I take certain
items out of the org file and turn them into individual prompts for
the model to work on. Over time I can make the research results
progressively more structured. I can even create structures for the
model to fill in.

This process of taking items off the org-mode heap and giving them to
Claude, I can automate. But first I need to demonstrate that the
process has value and is worth automating.

Essentially it's all about developing a valuable, repeatable process,
and then fixing the bottlenecks.
