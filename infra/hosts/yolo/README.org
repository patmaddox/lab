#+TITLE: yolo - an untrusted dev box for AI agents

Agents on yolo work as root: they build with poudriere, run bhyve
guests, and install what they like. Nothing on it is trusted. It is
cabled straight to rowdy's igb3, and rowdy lets it reach the internet
and nothing else. It holds no secrets but its own host keys and
password hashes.

* Build

On beastie, signed in to 1Password:

: redo yolo.be.zfs

The result is a ZFS send stream of a FreeBSD 15.1 pkgbase boot
environment with =dist/= applied and secrets from
=op://Personal/yolo-secrets=. It holds password hashes and private
keys, so it is mode 0600 and ignored by jj. Delete it after deploying.

* Install

yolo is installed from a USB stick. On beastie, signed in to
1Password:

: redo yolo-installer.img

This is a one-off, so =all= does not build it.
=infra/scripts/bsdinstall-stick.sh= makes it from the FreeBSD 15.1
memstick, as released, with a slice added that holds =yolo.be.zfs= and
the installer. It holds what the stream holds, so it is mode 0600 and
ignored by jj. Write it to the stick, here da0:

: dd if=yolo-installer.img of=/dev/da0 bs=1m

Boot yolo from the stick, choose Shell at the installer's welcome
screen, and run:

: mount -r /dev/ufs/installer /media
: sh /media/install.sh nda0

=install.sh= with no disk lists the disks. It asks you to type the
disk again, then lays out the disk as Auto (ZFS) on GPT (UEFI) does,
with no swap, as =stick.conf= asks. =dist/etc/fstab= finds the EFI
partition by the label bsdinstall gives it, efiboot0. Then it imports
the stream as yolo-15.1, activates it, and destroys the stock default
boot environment.

Remove the stick and reboot. Then wipe the stick, and delete
=yolo-installer.img= and =yolo.be.zfs=.

* Upgrade

Copy the stream to yolo, then as root:

: bectl import yolo-15.1 < /tmp/yolo.be.zfs
: rm /tmp/yolo.be.zfs
: bectl activate -t yolo-15.1
: shutdown -r now

=activate -t= boots the new BE once; if it fails, the next reboot
returns to the old one. Once it works, make it permanent with
=bectl activate yolo-15.1=.
