#+TITLE: yolo-jail - jails for agents on yolo

yolo-jail builds the ZFS templates that yolo's jails are cloned from,
and clones them.

* Build

: redo yolo-jail.pkg

* Install

Copy =yolo-jail.pkg= to yolo, then as root:

: pkg add yolo-jail.pkg

* Templates

As root on yolo:

: yolo-jail-template <template>

=yolo-jail-template= creates =zroot/jails=, mounted at =/jails=, if it
is missing. It installs base and the template's packages and users,
from =templates/<name>.conf=, into =zroot/jails/templates/<name>=.
Each user gets unrestricted =doas=. Then it takes the snapshot
=@ready= that jails are cloned from.

It refuses to replace a template that exists. To rebuild one, destroy
it and its clones first.

* Clones

: yolo-jail-clone <name> <template>

=yolo-jail-clone= clones =zroot/jails/instances/<name>= from the
template's =@ready= snapshot, unless it exists. A jail's config runs
it as =exec.prepare=, so the first start creates the jail. Only the
admin destroys a jail, to start it over.

* Repos

: doas yolo-git-init <owner>/<repo>:<branch> ...

=yolo-git-init= makes each upstream repo that jails clone,
=/git/<owner>/<repo>.git=, and the datasets that hold it, those that
are missing. =zroot/git=, mounted at =/git=, has =exec=off= and
=setuid=off=, so nothing there runs. =zroot/git/<owner>= holds an
owner's repos. Both it and the repos belong to the user who ran
=doas=, and it makes the repos as that user, so no git runs as root.

It points each repo's =HEAD= at =<branch>=, the branch a clone checks
out, every time it runs, so changing the branch and running it again
changes it on yolo. It prints each repo it makes and each =HEAD= it
changes.
